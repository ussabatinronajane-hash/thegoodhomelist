# Writing reference

Quick rules to keep every guide consistent. This file is not published.

## Title tag
- Under 60 characters so it does not truncate in Google
- Primary keyword in the first three words
- Include the year only if the guide is genuinely refreshed each year

## Meta description
- 140 to 155 characters
- Written to earn the click, not to summarise the page
- Include the primary keyword once, naturally

## Structure
- One H1 only, which is the title field
- H2 for main sections, H3 for individual products
- Answer the core question within the first 100 words
- Short paragraphs, two to four sentences

## Affiliate links
- Write a normal markdown link to any amazon.com URL
- The build automatically adds your tracking tag, rel="nofollow sponsored" and target="_blank"
- Never paste a link that already has someone else's tag, it gets replaced anyway

## FAQs
- Pull real questions from People Also Ask
- 40 to 60 word answers, direct answer in the first sentence
- These generate FAQPage schema automatically

## Internal linking
- Link to at least two other guides in the same category
- Link up to the category hub page at least once
- Use descriptive anchor text, never "click here"
